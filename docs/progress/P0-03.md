# P0-03 文档站交付记录

任务：JAV-5 / P0-03。分支：`codex/p0-03-docs-site`。日期：2026-11-09。状态：待独立审查。

## 交付内容

- VitePress1.6.4文档站、中文导航与侧栏、本地全文搜索、浅/深色主题、移动菜单。
- 首页使用纸色与深绿的手册风格，保留文档页的标准阅读结构。
- 课程索引数据与生成工具：9部分、01~45章，四篇试点标注计划状态，无假正文页面。
- 客户端按需加载的Mermaid组件，演示流程图和时序图，支持外观切换、错误提示和文字源码。
- Node/pnpm/依赖锁定、Vue类型检查、Windows/Linux文档构建CI、运行及子路径说明。

## 结构约定

`config.ts`负责导航、搜索和Markdown适配；`course.json`负责索引数据；生成后的`docs/course/index.md`供SSR和搜索直接读取。

首页是组合入口：`HomeHero`负责介绍与入口，`HomeRoute`负责九部分路线。`MermaidDiagram`只负责图表，接收只读code属性，使用Vue3 Composition API并在卸载时停止watch、丢弃过期渲染。无跨组件业务状态或额外全局状态管理。

## 本机验证

环境：Windows11、Node22.20.0、pnpm10.34.9，通过npx运行固定CLI，不修改全局pnpm或系统环境变量。

```sh
npx --yes pnpm@10.34.9 install --frozen-lockfile
npx --yes pnpm@10.34.9 docs:typecheck
npx --yes pnpm@10.34.9 docs:build
```

类型检查与SSR构建通过。另以`DOCS_BASE=/java-for-nestjs/`构建子路径版本；测试时用`DOCS_OUT_DIR`指定独立临时目录，预览时使用相同环境变量。
