# P6-03-A · 管理端与生成客户端

2026-11-20。使用Vue 3、TypeScript与Vite搭建管理端入口。Springdoc在真实后端生成[OpenAPI快照](../../project/apps/admin-web/openapi.json)，Maven测试比较运行时响应与版本库快照。Hey API由同一快照生成SDK，Vue调用生成的登录、身份查询和退出函数。

统一请求层将错误状态映射为用户提示并保留服务端请求ID。登录阶段将访问和刷新凭据留在进程内存。重载会重新登录，自动刷新、动态导航与管理功能在P6-03-B接入。[运行说明](../../project/README.md#管理端与-openapi)包括开发代理、构建和快照更新。

本机真实MySQL/Redis后端测试十四项通过，包含契约校验。浏览器验证错误密码提示与请求ID、登录后的身份读取、退出返回登录，以及390像素视口内表单无横向溢出。生成器与既有Prisma工具的传递依赖按审计结果定点更新，当前门槛下无高危或严重结果。
