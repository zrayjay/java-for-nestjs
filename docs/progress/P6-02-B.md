# P6-02-B · 用户与认证

2026-11-19。新增[身份建表迁移](../../project/java-modules/module-system/src/main/resources/db/migration/V1__accounts_and_sessions.sql)、[认证入口](../../project/apps/admin-server/src/main/java/dev/javafornestjs/capstone/AuthController.java)与[用户入口](../../project/apps/admin-server/src/main/java/dev/javafornestjs/capstone/UsersController.java)。请求或响应的用户ID使用十进制字符串，写接口拒绝未知字段及数值到字符串的自动转换。MyBatis-Plus提供Mapper装配。身份读取、凭据版本与刷新轮换用显式SQL。

签名使用外部RSA文件，访问令牌结合签名、发行者、受众、有效期和当前数据库会话检查。刷新凭据仅保存摘要，轮换锁定同一用户和会话。重放提交会话族撤销后才返回401。密码更新或用户停用使该账号的旧访问及刷新凭据失效。用户管理会在事务锁后重新检查管理员身份，且至少保留一个启用的管理员。

本机 Temurin 21、Maven 3.9.11 和独立 MySQL 8.4.7 运行真实HTTP验证。空库成功执行 Flyway V1；五项测试覆盖登录、过期、刷新重放、并发双重刷新、登出、用户增查改停用、权限与凭据版本。打包JAR用[文档命令](../../project/README.md#启动本地应用)生成的PEM文件启动，健康、登录和身份接口均返回200。

独立规范和规格复核提出运行说明和JSON标量转换问题。已补测试数据库、PEM及首启管理员步骤，并以数值型部门ID的HTTP 400断言验证修复。Linux双JDK运行见[后端CI](../../.github/workflows/capstone-backend.yml)。角色、菜单与订单权限接入由P6-02-C继续完成。
