平台管理员标记与订单角色分别管理。每个订单动作单独合并同名权限的范围，部门读取不会扩大本人取消范围。角色变动在现有会话的下一次查询生效。菜单树按当前能力过滤，PATCH保留省略字段，显式空父菜单将条目移到根层。循环父子关系和删除非叶节点返回409。

真实MySQL与HTTP测试核对匿名401、普通用户管理403、合法角色分配、动态数据范围、菜单树和节点编辑，以及并发撤销最后管理员的保护。订单范围通过真实授予的角色及订单授权接口取证。P6-02-D接入订单HTTP和SQL后再验证跨部门404、状态修改与历史副作用。
