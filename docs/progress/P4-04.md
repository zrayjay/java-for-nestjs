## 验证矩阵

| 输入/故障 | 实际结果 | 合法对照 |
|---|---|---|
| 输入超过1MiB字节 | 实测存储前拒绝、有界读取；输出另有源码上限，未独立构造输出超限夹具 | 小型RGB/RGBA有效PNG重编码成功 |
| 错误MIME/后缀/PNG签名 | 拒绝类型伪装 | image/png及真实PNG结构通过 |
| ../、反斜杠、绝对路径、CRLF名字 | 拒绝，不由输入构建对象路径 | 服务端随机UUID键，不含原名 |
| 超大IHDR尺寸/像素 | 解码前拒绝 | 宽高预算内像素保持一致 |
| 重复IHDR、交错路径、8MiB压缩膨胀 | 完整结构/受限格式/解压预算拒绝 | 唯一头、CRC、连续IDAT和完整IEND |
| 有效tEXt含标记 | 重编码后无标记，像素保留 | 不是只接受空图片做假安全 |
| 跨用户/匿名/非法对象键下载 | owner/actor/键校验拒绝 | 正确owner实际SDK取回字节 |
| 直接匿名对象URL | 真实HTTP403 | 授权服务端SDK可读取 |
| 公有桶策略 | 构造阶段保守拒绝已有策略 | 无策略私有桶正常工作 |
| infected或扫描器异常 | 不存对象，不伪造clean | not_configured明确返回未配置，并允许受限PNG教学保存 |
| 上传审计失败 | 尝试删除刚写对象；真实服务验证成功补偿 | 正常审计只含actor/action/随机key |
| 补偿删除也失败 | 单测保留主因+补偿因、核对同一键 | 不宣称跨系统原子性或自动恢复 |
| 下载审计失败 | 单测不返回字节并关闭流 | 正常读取有最小审计事件 |

## 证据与边界

修后首次真实服务[Files43815795277](https://github.com/zrayjay/java-for-nestjs/actions/runs/43815795277)在21/25各Java7+Node6通过；新增隔离单测后的[Files43857439613](https://github.com/zrayjay/java-for-nestjs/actions/runs/43857439613)两JDK完整成功，Java11（PNG4+对象3+单元4）、Node10（服务6+单元4）。Vitest2另在[Unit43817767580](https://github.com/zrayjay/java-for-nestjs/actions/runs/43817767580)四环境两轮执行，不与Files计数相加冒充同一套测试。

实际服务来自官方MinIO固定commit、Go1.24.2构建；原Docker Hub镜像拉取失败保留记录。不存在将空SDK mock当服务通过；只有稀有补偿/审计故障用隔离单测，边界已说明。

没有Multipart HTTP入口或文件上传经过JWT链的集成声明；trustedActor由上层认证上下文提供，不能从客户端JSON取owner。仅实现扫描扩展接口，未接真实病毒引擎；CRC不等于杀毒。信任存储管理员，构造时策略检查不防后续特权改策略，未审计完整IAM/ACL。P6必须在整合入口重新验证实际上传权限/响应头/请求总量/超时，不能据本记录提前标毕业项目完成。
