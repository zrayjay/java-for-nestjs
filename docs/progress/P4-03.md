## 负例与合法对照

| 场景 | 实际拒绝/不变量 | 合法对照与源码场景 |
|---|---|---|
| 未认证、Cookie凭据 | GET /tasks为401，Cookie不认证 | 显式合法Bearer200；passwordsAreHashedAndOnlyExplicitBearerCredentialsAuthenticate |
| 动作权限 | Cara写任务403 | Alice创建201；buttonPermissionMetadataDoesNotReplaceDirectServerRejection |
| 部门读取 | Alice读Bob任务404 | Bob合法创建201，Admin具全局权限可读200；departmentAndOwnershipRestrictionsApplyBeforeLimitAndWrites |
| 本人写范围 | Erin同部门能读但改删Alice任务404 | Alice本人PUT200/DELETE204，Admin全局改删成功；同一范围测试 |
| LIMIT前过滤 | Bob较小id不能挤掉Alice部门列表 | Alice limit1得到本部门第一条，范围在SQL WHERE而非取后过滤 |
| 角色管理与即时撤权 | 无role:manage不能调用管理接口；撤权后旧Access403 | Admin更新角色，合法权限当次可用；permissionChangesApplyToTheExistingAccessToken |
| Access到期 | 固定Clock到边界即401 | 仍有效Refresh签出新Access可用；accessExpiryIsStrictButRefreshCanIssueANewAccessToken |
| Refresh轮换及重放 | 已消费Refresh401，撤销族在事务提交后保留 | 首次轮换成功；重放后新旧族凭据不能再用 |
| 并发Refresh | 仅一次轮换成功；另一次重放撤销整个族 | 不宣称并发刷新无损重试；concurrentRefreshHasOneWinnerAndReplayInvalidatesItsFamily |
| 注销/禁用/会话到期 | Access与Refresh均按服务端族/用户状态拒绝 | 正常用户同协议成功；禁用登录同通用401，不泄露账号细节 |
| 凭据版本 | auth_version提升后两类旧凭据401；并发锁读到当前版本 | 新登录绑定新版本可用；credentialVersionInvalidatesBothTokenKindsAndNewLoginBindsTheNewVersion及锁等待测试 |
| 签名/算法/声明 | 错误签名、none、issuer/audience错误、9项必需声明遗漏拒绝401 | 合法RS256成功；signatureAlgorithmIssuerAudienceAndRequiredClaimsAreValidated |
| 请求上下文隔离 | 并发不同身份不能串owner/权限/审计requestId | concurrentDifferentUsersKeepOwnershipAndAuditCorrelationIsolated |
| 审计故障 | 任务写入500且SQL回滚，不留下未审计行 | 合法写和审计同事务提交；auditFailureRollsBackTheTaskInsteadOfLeavingAnUnauditedWrite |
| 运维指标 | 匿名401、成员403 | Admin读真实Micrometer/有限Node摘要200，标签不含requestId |
| 追踪不授权 | 合法traceparent且无Bearer仍401 | 合法Bearer+W3C上下文，SERVER→真实SQL span父子关系正确 |

两个端具体框架和错误位置不同，断言针对共同业务语义。404用于隐藏记录存在性，不是省略动作权限。已开始请求的权限是入口快照，当前实现不宣称撤销取消所有在途工作。
