# P6-02-E · 事务审计与菜单缓存

2026-11-19。[审计与菜单版本迁移](../../project/java-modules/module-system/src/main/resources/db/migration/V4__audit_and_menu_revision.sql)记录成功的管理、订单变更、登录、登出及已检测的刷新重放。普通业务写入与审计在同一MySQL事务提交。重放先提交会话撤销，再写审计。施加真实审计表约束后，已撤销的访问及刷新令牌仍返回401，审计失败输出带请求ID的脱敏告警。

普通用户不能查审计。集成测试用返回头的请求ID检索写入事件，校验事件和捕获的日志不包含密码或令牌。审计覆盖上述事件，常规读请求和失败登录不写审计表。

[菜单定义缓存](../../project/java-modules/module-system/src/main/java/dev/javafornestjs/capstone/system/MenuCatalog.java)按数据库版本读取。菜单写入更新版本，旧缓存键按TTL退出。权限从MySQL实时计算，Redis故障时回源。集成测试证实真实缓存命中、变更后使用新版本、Redis暂停时回源，并在故障窗口直接验证无权限的订单请求返回403。

本机Temurin 21、MySQL 8.4.7、Redis 7.4.6共十三项通过，0失败、0跳过。后端CI在两个JDK上独立启动服务并执行同一组测试。
