```sh
npx --yes pnpm@10.34.9 install --frozen-lockfile
npx --yes pnpm@10.34.9 format:check

./mvnw --batch-mode --no-transfer-progress clean verify
npx --yes pnpm@10.34.9 examples:build
npx --yes pnpm@10.34.9 examples:test
npx --yes pnpm@10.34.9 examples:verify
npx --yes pnpm@10.34.9 docs:typecheck
npx --yes pnpm@10.34.9 docs:build
```

Windows用`.\mvnw.cmd`替代`./mvnw`。Prettier3.9.10检查JS/TS/Vue/CSS/JSON/YAML，Markdown不自动重排；Checkstyle10.26.1在Maven validate阶段检查reactor的Java生产及测试源码。独立兼容探针不属于reactor，不能据此声称所有Java依赖完成漏洞扫描。

`foundation.yml`在Ubuntu24.04和Windows2025分别运行Java21/25、Nest构建及测试、3端×9输入契约。Linux服务任务执行Compose就绪等待、MySQL应用用户SELECT1、Redis PING并清理容器（保留数据卷）。`docs.yml`提供双平台类型检查、构建及断链阻断；`compatibility.yml`继续验证独立真实数据库探针。
