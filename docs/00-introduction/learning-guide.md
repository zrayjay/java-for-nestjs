# 学习指南

## 你需要哪些基础

能够使用 TypeScript、Node.js、NestJS 构建 REST API，熟悉 Controller、Service、DTO、依赖注入、Guard、ORM 与 JWT，并能使用 Git、pnpm、MySQL 和 Docker。

不要求已有 Java、JVM、Maven、Spring、Servlet 或 JDBC 经验。

## 建议学习顺序

1. 第 01~05 章：认识 Java 工具链、编译执行与 JVM。
2. 第 06~12 章：掌握类型、对象、泛型、集合、异常和并发。
3. 第 13~16 章：理解 Maven、多模块与依赖边界。
4. 第 17~28 章：完成 Spring Boot API、校验、数据库与事务。
5. 第 29~37 章：实现认证授权、缓存、审计、测试和诊断。
6. 第 38~41 章：验证消息、可靠性、容器和交付机制。
7. 第 42~45 章：完成模块化单体与 Vue3 管理端毕业项目。

课程目录和每章知识点见 [实施计划](../../JAVA-FOR-NESTJS-IMPLEMENTATION-PLAN.md)。16 周仅为课程设计参考，不是学习结果保证。

## 怎样检查自己学会了

| 层级 | 要完成的事情 | 检查证据 |
|---|---|---|
| L1 | 使用 Java 完成语言与工程练习 | 编译、运行和单测结果 |
| L2 | 编写可用 Spring Boot REST API | 用户 CRUD 与集成测试 |
| L3 | 实现安全、事务、缓存与审计 | 越权拒绝、事务回滚与缓存测试 |
| L4 | 构建、部署和观测完整项目 | CI、Compose、操作手册 |
| L5 | 解释性能与可靠性边界 | 性能测量与故障恢复报告 |

阅读每个知识点时先连接已有 NestJS 经验，再验证类比边界；运行对照代码，完成练习后核对验收条件。不要只凭语法相似推断机制相同。
