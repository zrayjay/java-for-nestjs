# ADR-0004：分离技术准入与读者效果验证

日期2026-11-10，状态：本轮执行采用。

## 背景

G1四篇样章的两轴独立技术/结构审查、真实实验和CI已经通过，真实读者能否指出至少三项差异仍未验证。报告该缺口后，用户再次要求“继续完成剩余的任务”，并在面板将JAV-14/15/16置为done（09:39，后续读取确认）。本轮据此继续课程实施，不将缺少读者反馈伪写为验证通过。

## 决定

将阶段的技术准入与读者效果验证分别跟踪。G1技术准入已通过，允许依次实施P2及后续阶段；各后续阶段仍必须完成适用实验、独立审查和CI。G1面板按用户主动验收保留done，读者效果条目保持未验证；后续任务不能由Agent自动done。

真实读者反馈并入既有P7-03试学任务的必查清单，至少三条机制差异仍须由真实读者表达并核对；最终G7/正式课程Release不得以AI审稿或CI代替。此决定不取消试学、不提前完成P7-03、不把后续章节批量标为完成。

## 后果

避免将教学内容实施无限等待于读者时间安排。风险是后续章节可能受试学反馈影响而返工；通过逐章审查、保留未验收状态和最终发布门禁控制。四篇及其余章节的完成状态仍以真实验收为准。实现继续使用用户指定的唯一main分支。
